## 💻 Como Rodar Localmente

Por ser um projeto web estático puro, você não precisa de nenhuma dependência pesada para executá-lo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/rafa10bjj/portfolio-rafael.git
   cd portfolio-rafael
   ```

2. **Abra o projeto:**
   - Basta abrir o arquivo `index.html` diretamente em qualquer navegador moderno.
   - Ou utilize a extensão **Live Server** no VS Code.
   - Ou utilize o Node.js:
     ```bash
     npx serve .
     ```

## ☁️ Como Fazer o Deploy na Vercel via GitHub

### Passo 1: Subir o projeto para o seu GitHub
Abra o terminal no diretório do projeto e execute:

```bash
# 1. Inicializar o Git (se ainda não tiver feito)
git init -b main

# 2. Adicionar os arquivos e criar o commit
git add .
git commit -m "feat: portfolio profissional de Rafael Rodrigues pronto para deploy"

# 3. Criar o repositório no GitHub (via interface web ou CLI) e vincular:
git remote add origin https://github.com/rafa10bjj/SEU-REPOSITORIO.git

# 4. Enviar os arquivos para o GitHub:
git push -u origin main
```

### Passo 2: Conectar o GitHub à Vercel
1. Acesse [vercel.com](https://vercel.com) e faça login com sua conta do **GitHub**.
2. No painel principal, clique no botão **"Add New..."** ➔ **"Project"**.
3. Na lista de repositórios, localize e clique em **"Import"** no repositório do seu portfólio.
4. Na tela de configuração:
   - **Framework Preset:** Selecione `Other` (ou deixe automático).
   - **Root Directory:** `./` (deixe padrão).
   - **Build and Output Settings:** Não precisa alterar nada (o `vercel.json` já cuida de tudo automaticamente).
5. Clique em **"Deploy"**.

Em poucos segundos, seu portfólio estará online no ar, com certificado SSL gratuito e domínio otimizado (exemplo: `https://portfolio-rafael-rodrigues.vercel.app`)!
